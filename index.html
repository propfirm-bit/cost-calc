Futures Prop Tools

先物プロップ ツール集

プロップファームトレーダーの意思決定を助ける無料計算ツールです。全てブラウザ完結・登録不要。ファーム別の価格・ルールデータは定期的に更新しています。

TOOL 01

実質コスト計算機

チャレンジ料+リセット料+アクティベーション費を合算した「合格までの総額」を7ファームで比較。条件を変えると即並び替わります。

料金比較
TOOL 02

コンシステンシー計算機

日次損益を貼り付けるだけ。最良日の比率が評価中・payout申請時の両基準に収まっているかを同時判定し、分散に必要な額と日数を算出。

一貫性ルール
TOOL 03

DD計算機・ロット逆算

トータルDDと日次損失の2重制限に対応。DD残と損切り幅から最大ロット数を逆算。銘柄別のティック価値変換器付き。

リスク管理
TOOL 04

payoutシミュレータ

月間利益を入れると、ファーム別の分け前・出金上限から「手取り額と必要なpayout回数」を一括比較します。

収益シミュレーション
  • 表示の価格・ルールは各ツール内に調査日付きで明記しています。ファームは頻繁に改定を行うため、申込・申請前に必ず公式サイトで再確認してください。
  • このサイトにはアフィリエイト広告を含みます(PR表示のあるリンク経由での申込により報酬を得る場合があります)。
全ツールの計算はお使いのブラウザ内で完結します。入力した数値は送信・保存されません。
